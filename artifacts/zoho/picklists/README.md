# Picklist value starters (non-secret)

Zoho picklists are usually created in **Setup → Modules and Fields**. These CSVs are **suggested values** to copy or to reconcile with your org’s wording (English UI per round 4).

| File | Use on |
|------|--------|
| `lost_reasons.csv` | Deal **Lost Reason** (required when Closed Lost) |
| `payment_terms.csv` | **Quote** (and optional Deal) **Payment terms** |
| `competitors_template.csv` | Deal **Competitor** — **replace** `REPLACE_ME_*` with real names |
| `line_of_business.csv` | **Lead** line (Production / MPS) — should match pipeline choice on convert |

**Note:** Zoho import of picklist *values* is module-specific; many admins paste values manually or use bulk options where supported.
